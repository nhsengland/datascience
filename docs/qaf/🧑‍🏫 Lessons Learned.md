*Capturing lessons ensures continuous improvement and prevents repeat mistakes across projects.*

**Success Criteria:** Lessons are recorded systematically and used to inform future projects.

* **RED:** No capturing and learning from mistakes.
* **AMBER:** Lessons captured inconsistently or not applied.
* **GREEN:** Formal and systematic process for continuous improvement throughout the project. Pro-active sharing of lessons learned to benefit other projects.

## Good Practice Guidance

| MSC | Good Practice |
| --- | --- |
| SHOULD | * At project initiation there is specific consideration of what can be learnt from previous work that could be applied in this project. |
| SHOULD | * There is a process for continuous improvement and learning through the project. |
| SHOULD | * There is a dedicated session and formal capture of lessons learned at project completion including all team members. |
| SHOULD | * Where lessons are relevant beyond immediate project they are fed into relevant processes (e.g. updating guidance, tasking Function Teams, escalating to SMT). |
