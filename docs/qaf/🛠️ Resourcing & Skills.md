# 🛠️ Resourcing & Skills

INLINE

*Projects require a team with the right skills and sufficient capacity to deliver to time, quality and scope.*

***Success Criteria:** Team resources and skills are appropriate, available, and balanced for project needs.*

* **RED:** Team lacks key skills or capacity.
* **AMBER:** The team partially meets the resource and skills required to deliver the project, with some gaps or imbalances.
* **GREEN:** Team fully resourced and skilled to deliver core requirements, and able to call on additional specialist resource as needed.

## Good Practice Guidance

| MSC | Good Practice |
| --- | --- |
| MUST | * Evaluate the skill and capacity of the assigned project team relative to the requirements, expected timescale and target quality standard for the project. Identify any mismatch. |
| MUST | * Where specific upskilling will be needed (e.g. to adopt a new tool or technique) make the identification and completion of relevant training part of the project delivery plan. |
| MUST | * Where skill or resource shortfalls remain, mitigate by rescoping project deliverables and/or flagging dependencies and risks to customer and senior DS staff. |
| MUST | * Identify any supplementary skills needed (e.g. project management, data engineering, user research) and plan how these will be sourced. |
| MUST | * Plan ahead for staff rotations - Specify skill and resource requirements in the Business Planning Cycle. |
| SHOULD | * Plan ahead for effective hand-overs for changes in staffing:   + Use onboarding and offboarding checklists (e.g. for access to systems).   + Maintain an orientation pack for new starters (this might include commissioning notes, past show & tells, etc.).   + Develop runbooks for critical processes that may need to be handed over.   + Mitigate single points of failure through documentation and cross-training. |
