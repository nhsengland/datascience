# DS*xxx: Data*

_High-quality, appropriate data is the foundation for reliable analysis._ _[📊 Data](../%F0%9F%93%8A%20Data.md) is an essential part of delivering a quality data science project._

## Data Sources

This table sets out the minimum documentation expected to evidence good data management practice.   
List all data sources considered for your use case, including briefly covering data sources that may have been considered but ultimately not used.  
Create a copy of this table **for each data source** used or considered in the project.

## Data Linkage

Many data science projects require linkage of multiple datasets to create a combined asset as a foundation for subsequent analysis.

Record here the approach taken to linking across data assets, whether through a bespoke approach in this project or utilising other services such as Master Patient Index, Subject of Care Index or Pseudo IDs available in the analytical platform being used.

You may want to consult the $Data Linkage Hub$ for advice on approaches to data linkage.
