## Closure Checklist:

See the below list for activities to complete when closing your project.

Strongly encouraged:

- Deliver a presentation
- Create or update the project page on the DS website
- Ensure documentation of all standard BAU processes 
- Create or update project KERs 
- Finalise projects lessons learnt
