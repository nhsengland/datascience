# 🧪 Approach & Methodology

INLINE

*Projects must have a clear analytical approach, using methods that are appropriate and proportionate to the problem. Flexibility is important as projects evolve.*

**Success Criteria:** The chosen methodologies are appropriate for the project’s objectives and implemented correctly.

* **RED:** The proposed methodologies and tools are inappropriate for the project, or decisions to change the methodological approach are not justified.
* **AMBER:** The proposed methodologies and tools are broadly suitable, but decisions to select / change the methodological approach are not well documented and justified.
* **GREEN:** The proposed methodologies and tools are appropriate for the project. Any decisions to change the methodological approach are documented and well-founded. Validity of choices and verification of implementation are documented.

## Good Practice Guidance

| MSC | Good Practice |
| --- | --- |
| MUST | * There is sufficient confidence that the chosen methodologies are appropriate for the problem. |
| SHOULD | * Multiple methods are considered across different stages to build the evidence base that supports the decision-maker throughout the process. * Any changes to the methodological approach are documented and well-founded. |
| COULD | * Create a light-touch 'Verification and Validation log' capturing assurances from [peer review](./%F0%9F%91%80%20Peer%20Review.md), [code review](./%F0%9F%91%A8%E2%80%8D%F0%9F%92%BB%20Coding%20Quality.md), and evidence supporting [assumptions](./%F0%9F%92%AD%20Assumptions.md) in one place. |
